# 隐私与公开发布检查

本仓库使用新建的文件白名单快照，避免把本机历史提交和忽略文件带到公开仓库。检查针对公开文件，不承诺自动扫描能识别一切敏感信息。

## 未上传的内容

- DevEco 开发者签名私钥、签名密码、证书、授权 profile 和真实签名配置。
- 实验 MFi 身份私钥/证书、原始 APK、个人开发签名 HAP。
- 设备序列号、实际蓝牙地址、配对数据库、运行时接收端私钥。
- 实际热点密码、热点名称、网络探测记录、诊断日志、开发日志与研究中间文件。
- 本机账户路径、微信目录标识、原始实机照片及其元数据。
- 含手机自定义名称、地图位置、常用地点或拍摄环境的原版 PPT/视频。

仓库只包含无签名 `build-profile.template.json5`；实际 `build-profile.json5` 在本机复制并由 DevEco 配置签名，不进入 Git。`.gitignore` 阻止常见私钥、证书、应用包、日志及认证目录进入后续版本。

## 已保留的内容

源代码、GPL 与归属、无签名构建模板、合成测试、原生适配说明和公开版介绍。测试中的 `AA:BB:CC:DD:EE:FF`、`10:20:30:40:50:60`、私网 IP 与测试密码是合成夹具，协议中的固定公钥参数/素数不是用户密钥。

公开 PPT 删除了带个人内容的嵌入媒体，移除作者/最后修改人、制作路径和嵌入缩略图；不是在原始图片上盖一个仍可撤去的遮挡层。原始 PPT 和原始视频仍只保留在本机。

## 应用数据行为

密码默认仅存在当前运行内存；启用记住密码后保存在鸿蒙安全资产库，设备解锁时读取且不同步。非密码设置保存在应用私有 Preferences。诊断复制前替换已知私人字段、网络地址和设备地址，应用不会自动上传诊断。

## 再次发布前

运行 `npm run audit:public`；检查 `git diff --cached`，尤其是签名配置与新增图片/压缩包。扫描拒绝典型凭据格式、个人账户路径和未批准二进制，并检查 PPT ZIP 中的 XML、关系和媒体白名单。扫描只报告文件/类别，不输出检测到的秘密值。

提交 issue 或截图前仍请人工检查设备名称、地点、通知和密码，不上传完整 hilog 或 Preferences 数据。
