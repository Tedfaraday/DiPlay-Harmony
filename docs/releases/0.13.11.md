# DiPlay Harmony 0.13.11

原生 HarmonyOS NEXT 无线 CarPlay 显示接收端，使用 ArkTS / ArkUI 与原生 C++ API。基于 DiPlay 0.2.12 的协议实现独立移植，遵循 GPL-3.0-only；不是 Apple 官方认证产品。

## 本版变化

视频接收队列改为 64 KiB 分片归并和 16 MiB 字节上限，取消按 TCP 回调数量误触发的限制；每批最多解析 64 包，保留余包继续消费。仍按顺序认证、解密并在会话关闭后清理异步结果。

控制服务发现类型对齐为 `_carplay-ctrl._tcp`，来源仍限定为已认证手机。蓝牙引导释放需同时满足手机 disableBluetooth 指令已应答及当前 Wi-Fi iAP2 认证完成。修正音频格式校验，补充输入延迟声明、麦克风权限与默认关闭的回传实验开关。

认证后的 iAP2、AirPlay 能力请求与音频控制命令补充固定白名单诊断；不新增订阅或伪造音频流。消息摘要去重并限制数量，不记录标识符、热点密码或原始载荷。

## 验证与限制

22 个测试文件、185 项检查通过，覆盖认证、重放保护、协商、生命周期、权限模拟及视频碎片处理。完整本地版本约 98 秒的会话中画面和触控流畅，未见队列超限、视频停止或自动重连；未完成长时间、多设备兼容性验证。

音频仍未解决：声音来自 iPhone，输出列表没有新增设备，30 秒音频 SETUP 和活动音频流均为 0。手机报告无线 CarPlay 可用与完成交接不代表音频路由注册成功。目标控制服务发现仍未验证成功。麦克风实验和合成解码自检不代表真实音频输入、输出或 Siri 已可用。

应用需保持前台；锁屏或切换应用会断开。支持无线画面、单指触控、沉浸横屏、三指退出面板、配置保存与前台有限重试。
